# Vowel Studio visual fidelity record

Reviewed 6 September 2026 against the original generated
[home concept](../design/vowel-home-concept.png),
[practice concept](../design/vowel-practice-concept.png), and
[vowel-pairs concept](../design/vowel-pairs-concept.png).

| Anchor | Implemented result | Deliberate adjustment |
|---|---|---|
| Expressive stacked hero title | FIND / YOUR / VOICE with forest serif typography | Responsive wrapping keeps the mobile action visible. |
| Circular botanical hero | Original Pippin garden and concentric sound rings | Art height capped at 720 px to balance title and primary action. |
| Warm paper and green system | Ivory, forest, lime, coral throughout new learning pages | Existing care pages retain task-specific layouts. |
| Circular recording focus | Clear prompt, microphone, 7.0 s countdown and actual waveform | Timer begins only after permission; idle animation never pretends to be audio. |
| Five paired vowel columns | A/E/I/O/U with correct short and long Tamil symbols | Generated concept glyph errors are replaced with actual curriculum text. |
| Consistent Pippin | Orange kitten, blue eyes and blue bandana in every new illustration | The concept's accidental bird is not carried into the product. |
| Result hierarchy | Large measured score, identity, length, voiced seconds and confidence | Real model results replace illustrative percentages. |
| Quiet rewards | Restrained success glow, Pippin reaction and earned stars | Reduced-motion mode removes nonessential animation. |
| Functional navigation | Home, Practice, Games, Evaluate, Progress, account and mobile menu | Original lessons and care links remain reachable. |

Inspected rendered views at 1536 × 1024 and 390 × 844. Automated layout checks
also cover Playwright's desktop viewport. The final layout corrections use
shrinkable evaluation grid columns, bounded decoration and large control targets.
Public and learning controls have names, focus states and real destinations.

Allowed visual references: circular composition, atmospheric pacing and expressive
type from the user's reference. All product copy, branding, Pippin/garden art and
implemented interfaces are original to this project; no reference-site assets or
branding were copied. Model/dataset attribution remains visible at `/credits` and
from the practice screen.
